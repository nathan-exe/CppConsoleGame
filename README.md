# A simple windows console vs game made in c++.

Player 1 (sitting to the left of the keyboard, playing with their right hand) : 
- esdf -> move
- w -> shoot

Player 2 (sitting to the right of the keyboard, playing with their left hand) : 
- ijkl -> move
- : -> shoot
